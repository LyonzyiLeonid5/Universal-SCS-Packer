# Microsoft DirectStorage runtime

`dstorage.dll` and `dstoragecore.dll` are the official x64 redistributable
runtime files from the `Microsoft.Direct3D.DirectStorage` NuGet package,
version 1.3.0.

They provide the CPU GDeflate compressor used by `GDeflate.py` and are bundled
inside `UniversalSCSPacker.exe` by PyInstaller. See the accompanying Microsoft
license and notices files for redistribution terms.

Package: https://www.nuget.org/packages/Microsoft.Direct3D.DirectStorage/1.3.0
